# simplekit Template Project

This project is a basic starter for building new apps with [SimpleKit](https://github.com/CS-3035-2026/simplekit). Feel free to clone or fork it for coursework, a personal project, or just to play around with SimpleKit — you don't need to be enrolled in CS 3035 to use it.

## Getting Started

1. Clone or fork this repository.
2. Initialize the SimpleKit submodule:
   - `git submodule init`
   - `git submodule update`
3. Install dependencies:
   - `npm install`
4. Run the dev server:
   - `npm run dev`
5. Open the local URL it prints (usually `http://localhost:5173`) in your browser.

## Exploring the SimpleKit Examples

The [CS 3035 course website](https://CS-3035-2026.github.io) showcases a full set of SimpleKit example projects — HelloWorld basics, layouts, widgets, MVC, drawing, input events, hit testing, and event dispatch demos. They live in a separate repository that you can clone and run the same way:

```bash
git clone https://github.com/CS-3035-2026/examples.git
cd examples
git submodule init
git submodule update
npm install
npm run dev
```

Open the local URL it prints in your browser — the home page links out to every example.
